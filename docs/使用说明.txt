超表面阵列编码设计系统 (桌面便携版)
=============================================================================

【启动方式】
直接双击本文件夹内的：
  根目录的 启动设计系统.bat。
  首次使用请先运行 pip install -r requirements.txt 安装依赖。
  也可在项目根目录运行 python python/app_gui.py。
  Python源码统一位于python目录，MATLAB工具位于matlab目录。

【功能说明】
1. 普通波束支持正频率参数、1/2-bit 阵列和单波束/多波束赋形；实际器件频段需由单元响应确定。
2. 算法提供：
   - fast: 解析相位叠加与量化，再逐阵元尝试离散状态，保留目标函数的改进；
   - analytical: 仅执行解析相位叠加与量化；
   - ga_exact: 使用选择、交叉、变异与精英筛选进行遗传算法搜索。
3. 生成的 TXT 编码矩阵默认存放在本文件夹的 output\ 目录中，
   内容为逗号分隔的整数状态编号，1-bit 为 0/1，2-bit 为 0/1/2/3。
4. 波束权重为复场幅度权重，不直接等于最终波束功率比例。
5. 当前使用理想等幅阵列因子模型；波束功率和非目标杂散峰需结合方向图评价。

【OAM 涡旋波】
Python界面可切换涡旋波 (OAM)，支持目标阶数±1、±2，采用解析初始化加坐标下降。
要求2-bit、16到64之间的偶数方阵，周期不超过半波长，阵面边长至少4个波长。
提供局部圆盘及R=0.99圆盘的模式占比，保存JSON指标、NPZ复场与模式谱、PNG诊断图。
模式占比不是总辐射效率；环上绕转不证明高阶奇点居中或未分裂。
当前不包含深度学习，MATLAB不提供OAM求解。详见docs/涡旋波模式.md。
